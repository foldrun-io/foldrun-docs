foldrun — how it all fits together

A folder of markdown is a team. The platform is the office it works in.

1 · Four scopes, one rule

Nearest wins. An agent’s own file beats its workspace’s, which beats the account’s shared layer — the same cascade as CSS. That is the whole resolution model.

2 · What cascades, and what must be granted

LayerAgentWorkspaceSharedHow an agent gets it
skills ✓✓✓ inherited — names + descriptions only, full file read on demand
memory ✓✓✓ inherited — index generated from the files, loaded every run
scripts ✓✓✓ visible, but only runnable via bash or a declared tool
tools —✓✓ granted — nothing is callable until tools: [name]

Knowledge is safe to inherit; capability is not. A tool spends money and touches production, so reading one agent.md tells you an agent’s entire blast radius.
