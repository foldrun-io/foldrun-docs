account — shared by everything workspace — a trust boundary agent — one role

Reading down — everything in library/ reaches every workspace and agent beneath it, without any of them naming it.

Reading up is how a run resolves: an agent's own file beats its workspace's, which beats the account's. Nearest wins, at every step.

Only a workspace holds agents, flows, evals and state — everything that executes, or is produced by executing. The account holds what can be shared; the workspace holds what can run.
